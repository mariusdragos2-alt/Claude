    Conectare la GitHub

    Articolele sunt salvate în fișierul posts.json din repo-ul site-ului. Pentru a salva ai nevoie de un token GitHub, păstrat doar în acest browser.

    1. Deschide github.com → Settings → Fine-grained tokens.
    2. La Repository access alege doar repo-ul site-ului.
    3. La Permissions → Contents alege Read and write.
    4. Generează tokenul și lipește-l mai jos.
